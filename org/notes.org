+ dbcontext: DbContext is the main class in {ef core} that lets you work with a database using C# objects instead of SQL.
  + a short-life session with the real database.. in c# without actually writing sql
  + It
    1. knows:
         Which tables exist
         How C# classes map to tables
             maps rows to objects { classes with tables }
         How to read, add, update, and delete data
    2. almost auto opens/closes connection
    3. tracks and saves changes

DbContext → represents the whole database
DbSet → represents one table inside that database

Add() is on DbSet
SaveChanges() is on DbContext

| Feature             | DbContext                    | DbSet         |
| ------------------- | ---------------------------- | ------------- |
| Represents          | Whole database               | Single table  |
| Contains            | DbSets                       | Entities      |
| Handles             | Connection, tracking, saving | Querying data |
| Has `SaveChanges()` | Yes                          | No            |
| Used for            | Managing DB session          | CRUD on table |

# One More Important Thing

`readonly` is mostly for **fields**:

```csharp id="0jmvks"
private readonly ILogger _logger;
#+end_example

=init= is for *properties*:

=csharp id="2hycfe" public string Name { get; init; }=

=csharp id="5s72tp" public required string Name { get; init; }=

instead of old-style private readonly fields for data models.

| Type      | Meaning                                                                                                        |
|-----------+----------------------------------------------------------------------------------------------------------------|
| =string=  | must exist                                                                                                     |
| =string?= | may be null                                                                                                    |
