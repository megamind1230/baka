Linux is hardest because: Wayland restrictions
Important: Wayland intentionally blocks global keylog-like behavior.
So on Linux: X11 → easy,Wayland → harder
You may need:
    compositor-specific protocols
    portals
    GNOME/KDE integration
This is the biggest challenge in the entire project.

Wayland issue: Tauri's global shortcut plugin uses global-hotkey crate which doesn't support Wayland — it's a protocol-level limitation. Options:
1. Hyprland: bind = $super SHIFT, C, exec, /path/to/snapshot-shim where the shim signals the daemon
2. Sway: bindsym --to-code { "Mod4+Shift+C": exec ... } 
3. KDE: configure a custom shortcut in System Settings → Shortcuts → Custom Shortcuts that runs a D-Bus command
4. gnome: gsettings or an extension
The cleanest cross-compositor approach would be to add a Unix socket or D-Bus listener so the running daemon can be triggered by an external command. Want me to add that?
