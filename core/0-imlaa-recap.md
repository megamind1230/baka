# اللام الشمسية الـشمس

# التنوين
+ هي نون
  1) ساكنة
  2) على آخر حرف في الاسم
  3) لفظا لا خطا (بدلها فتحتان{نصب}/ضمتان{رفع}/كسرتان{جر})
+ في حالة النصب نكتب بعد التنوين ألف ... إلا لو الكلمة آخرها
  1. آخرها تاء مربوطة
     - مدرسة
  2. ألف لينة ( طويلة/ مقصورة )
     - عصا / فتى
  3. همزة (على ألف/قبلها ألف)
     - نبأ / سماء
# ـــت/ت أم ــة/ة أم ــه/ه؟

# شكل ألف المقصور(الألف اللينة)
نرجع لأصلها
+ لو كانت منقلبة عن واو --> تكتب ألف
  - نجا ( ينجو )
+ لو كانت منقلبة عن ياء --> تكتب ياء
  - رمى ( يرمي )

+ >> كيف نعرف الأصل ؟
  - في الأسماء: نبحث (المفرد/الجمع/المثنى/المونث السالم)
  - في الأفعال: نبحث (المضارع/تاء الفاعل المضمومة/المصدر)
# ألف الوصل/ همزة القطع
+ ألف وصل مكسورة أول الكلمة:
  1) تنطق همزة عند الابتداء بها
  2) تسقط عن الوصل بما قبلها
+ ألف مهموزة مكسورة أول الكلمة:
  - تنطق همزة عند (الابتداء بها/الوصل بما قبلها)

+ >> أشهر قواعد فحصها: الحركة على ياء المضارعة
  - لو مضمومة --> همزة قطع
    - إتقان ... يُتقن
  - غير ذلك  --> ألف وصل
    - اتصال ... يَتصل
# الهمزة المتوسطة والطرفية(المتطرفة)
+ يكون ما بين الهمزة وما قبلها (نزال)
  - تفوز فيه أقوى الحركتين
    1) الكسرة
    2) الضمة
    3) الفتحة
    4) السكون
  - الحركة الفائزة في النزال --> تفرض حرفها المناسب على الهمزة
+ وعندما تكون الهمزة مسبوقة بحرف مـــــد (واي)
  + تكتب على السطر في الغالب
