*** Task 2 & 3 merged
*About / The Idea I Chose*

#+begin_quote
simple but yet convenient oop app recommendation engine
#+end_quote

- This was a console application that takes user input (name, age, profession) and recommends useful software/apps based on their profile
- The core idea was to demonstrate all five pillars of Object-Oriented Programming in C#
- I created a base =User= class with private fields and init-only properties
  (encapsulation), and then built 7 derived persona classes --- =Student=,
  =Teacher=, =Developer=, =Designer=, =Writer=, =Artist=, and =Manager=
  --- each inheriting from =User= and overriding virtual methods for follow-up questions and recommendations (inheritance + polymorphism)
- A =UserFactory= implemented the factory pattern to abstract object creation (abstraction), and a =RecommendationEngine= processed any =User= polymorphically
- I also wrote a custom =UnknownProfessionException= class to practice custom exception handling, and integrated Serilog for structured logging to files

*Challenges*

- Polymorphism was the hardest concept to understand and implement .. sometimes i forgot =abstract / virtual / override=
- understanding that a =User= reference could call the correct child-class method at runtime took several iterations and debugging sessions

*Skills Learned*

- Encapsulation (private fields, init-only properties)
- Inheritance with constructor chaining (=: base(...)=)
- Polymorphism via =virtual=/=override= methods
- Factory design pattern for abstraction
- Custom exception creation and try-catch-finally
- Serilog structured logging (console + rolling file) {{awesome btw}}
- i did some debugging inside of both vscode/Rider (breakpoints, watch window, call stack)

*** Task 4 --- Avalonia File Organizer (lvl2-task-1) {the real action starts}
*About / The Idea I Chose*

#+begin_example
A cross-platform files organizer tool with 2 frontends: 
 - a CLI with both modes (interactive dashboard) and a one-shot mode
 - a desktop GUI built with Avalonia
I even created a standalone Bash script .. cuz i loved the idea
#+end_example

The tool scans a user-specified directory and organizes files through a
two-pass approach: first, files matching user-defined keywords or regex
patterns are moved into keyword-named folders, then remaining files are sorted
into category folders (imgs, docs, aud, vid, archives, installers, others)
based on their extensions

*Challenges*

- Learning Avalonia from scratch was the biggest hurdle ( the .axaml syntax, data binding, and MVVM structure ) were entirely new and weird to me
- I encountered several issues with the preview table's live matching (updating the UI as the user types patterns), which I solved by implementing =INotifyPropertyChanged= and using observable collections correctly
- Another challenge was handling edge cases in the file scanner: directories with permission errors, paths exceeding the system limit, and filename conflicts during reverse operations

*** Task 5 --- Kanban Board (lvl2-task-2)
*About / The Idea I Chose*

A multi-project ASP.NET Core 8.0 kanban board demonstrating four hosting paradigms

#+begin_quote
MVC, Razor Pages, Minimal API, and API Controllers
#+end_quote

all sharing a single =Kanban.Core= class library

Each project runs on its own port (5001 ==> 5004) with its own SQLite database

*Challenges*

Sharing a single EF Core DbContext across four different project types required careful dependency injection setup in each =Program.cs=

I also had to handle index conflicts during card reordering --- when dragging a card to a new position, multiple cards could share the same =Order= value. I resolved this by implementing a non-unique composite index on =(ColumnId, Order)= and writing the reorder logic to shift surrounding cards. Debugging SortableJS integration across all four projects was also time-consuming, especially ensuring the serialized data matched what each backend expected.

*Skills Learned*

- ASP.NET Core MVC (Controllers + Views)

- ASP.NET Core Razor Pages (PageModel + .cshtml)

- ASP.NET Core Minimal APIs (MapGet/MapPost)

- ASP.NET Core API Controllers

- Multi-project solution architecture with shared libraries

- EF Core dbcontext with SQLite (migrations, seeding, indexes)

- SortableJS for client-side drag-and-drop

- simple bootstrap 5 and jquery integration
