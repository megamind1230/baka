## marks
> go to mark with ==\`== or =='==
- [x]   :marks > list of marks
	- [x] ma > create/set local mark `a`
		- [x] mA > create/set global mark `a`
			- [x] make sure shada is enable for it to persist accross sessions `:set shada?`
	- [x]   \'a > jump to line of mark `a`
		- [x]   \`a > jump to exact position of mark `a`
	- [x]  y\`a > yank text to position of mark `a`
	- [x]  d\`a 
	- [x]  v\`a
### when to use marks
- reading large files
	- todo
	- stopped here
	- confusing part
- debugging
	- error
	- func call

## jumplist
- [x]   :jumps > list of jumps
- [x]   ctrl + i > go to newer position in jump list
- [x]   ctrl + o > go to older position in jump list
## change list
- [ ]   :changes > list of changes
- [ ]   g, > go to newer position in change list
- [ ]   g; > go to older position in change list
- [ ]   Ctrl + \] > jump to the tag under cursor
